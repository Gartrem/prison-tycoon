# Тюрьма Тикоон

Браузерная версия игры. Откройте опубликованный GitHub Pages сайт с телефона или компьютера. Для разработки используйте локальный HTTP-сервер: открытие index.html как файла не поддерживается.

Все файлы запуска находятся в корне. Исходники игровой логики и русские тексты сохранены в game-sources.zip. APK и локальный сервер для игры на сайте не нужны.

Прогресс сохраняется в браузере через меню игры. Сохранения с localhost автоматически на новый адрес не переносятся и между устройствами не синхронизируются.

Репозиторий содержит материалы исходной Prison Tycoon и предоставленные пользователем иллюстрации. Права на сторонние материалы принадлежат их правообладателям; публикация не предоставляет лицензию на их свободное использование.
